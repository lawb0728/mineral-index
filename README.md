# 矿物详情目录

这是可直接部署到 GitHub Pages 的静态矿物查询目录，入口文件为 `index.html`。

## 目录结构

- `index.html`：矿物目录、名称和化学元素检索、分类与晶系筛选。
- `单斜晶系/`、`等轴晶系/`、`六方晶系/`、`三方晶系/`、`三斜晶系/`、`四方晶系/`、`斜方晶系/`：按晶系归档的矿物详情页。
- `assets/crystvis/`：晶体结构交互显示所需的本地脚本。
- `.nojekyll`：让 GitHub Pages 按静态文件原样提供目录内容。

## GitHub Pages 发布

将本目录中的全部文件上传到 `lawb0728/mineral-index` 仓库根目录，然后在仓库设置中将 Pages 的发布源设为默认分支的根目录即可。

页面之间使用相对路径，移动到晶系文件夹后返回目录和晶体结构脚本路径均已同步调整，适用于本地打开和 GitHub Pages 在线访问。

## 本地查看

直接打开 `index.html` 可以查看目录和详情文字，详情页中的三维晶体结构建议通过静态文件服务访问，以避免部分浏览器对本地文件脚本加载的限制。
